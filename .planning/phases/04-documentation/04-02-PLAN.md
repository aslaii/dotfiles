**3. Scripting Addition** (per D-06):
Section header: `## Scripting Addition (Optional)`

Opening: "The scripting addition (`yabai -m signal`, space management, window opacity) requires a sudoers entry so yabai can load it without a password prompt."

Subsection `### Install the Scripting Addition`:
```bash
# Add sudoers entry (replace <yabai_hash> with output of shasum)
sudo visudo -f /private/etc/sudoers.d/yabai
```

Add the exact sudoers line format:
```
<user> ALL=(root) NOPASSWD: sha256:<hash> /usr/local/bin/yabai --load-sa
```

Step-by-step:
1. Get the hash: `shasum -a 256 $(which yabai)`
2. Get your username: `whoami`
3. Create the sudoers file with: `sudo visudo -f /private/etc/sudoers.d/yabai`
4. Add the line: `<username> ALL=(root) NOPASSWD: sha256:<hash> <yabai_path> --load-sa`
5. After Homebrew upgrades yabai, re-run step 1 and update the hash

Add note per research pitfall 3: "The current `yabairc` does not use the scripting addition. This section documents the setup for when advanced features (signals, space manipulation, window opacity) are needed."

### `switch_github_account`
```bash
switch_github_account <account_name> <git_name> <git_email>
```
- Switches the active GitHub CLI account (`gh auth switch`)
- Sets `git config --global user.name` and `user.email`
- Use at the start of a role script to ensure the right identity

### `kill_port`
```bash
kill_port <port_number>
```
- Kills any process listening on the specified TCP port
- Uses `lsof` to find the PID and `kill -9` to terminate

### `nvm_use_project_node`
```bash
nvm_use_project_node <directory>
```
- Reads `.nvmrc` or `package.json` `engines.node` from the given directory
- Runs `nvm use` or `nvm install` to switch to the correct Node version
