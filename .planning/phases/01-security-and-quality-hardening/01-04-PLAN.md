    ```yaml
    repos:
      - repo: https://github.com/koalaman/shellcheck-precommit
        rev: v0.11.0
        hooks:
          - id: shellcheck
            args: [--severity=warning, --external-sources]
            exclude: "macos/zsh/.*"

      - repo: https://github.com/scop/pre-commit-shfmt
        rev: v3.13.0-1
        hooks:
          - id: shfmt
            args: [--write, --indent=2, --case-indent]

      - repo: https://github.com/gitleaks/gitleaks
        rev: v8.30.1
        hooks:
          - id: gitleaks
    ```

    Key decisions encoded in this config:
    - `--severity=warning` on ShellCheck: avoids failing on style-only (info/style) findings
    - `--external-sources` on ShellCheck: follows `source` directives, matching the existing
      `shellcheck -x` convention from AGENTS.md
    - `exclude: "macos/zsh/.*"` on ShellCheck: excludes .zshrc and other zsh-specific files
      that use Zsh syntax ShellCheck cannot parse under bash mode (Pitfall 3 from RESEARCH.md)
    - `--write` on shfmt: hook fixes files in place (staged files get reformatted, not just
      flagged) — avoids the "shfmt exits non-zero without modifying" confusion
    - `--indent=2`: matches existing 2-space indentation in setup scripts
    - `--case-indent`: matches existing case branch indentation style
    - Do NOT add `--simplify` (`-s`) to shfmt: removed as default in v3.12.0-2 due to
      false positives (Pitfall 4 from RESEARCH.md)
    - `gitleaks` hook uses `--staged` by default (built into the hook) — only scans staged
      files, not full git history (Pitfall 5 from RESEARCH.md)
  </action>

    First create the directory if it does not exist:
    The Write tool will create intermediate directories automatically.

    Create `/Users/aslaii/dotfiles/.github/workflows/shellcheck.yml` with this exact content:

    ```yaml
    name: ShellCheck

    on:
      push:
        branches: ["**"]
        paths:
          - "**.sh"
      pull_request:
        paths:
          - "**.sh"

    jobs:
      shellcheck:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - uses: ludeeus/action-shellcheck@2.0.0
            with:
              severity: warning
              ignore_paths: macos/zsh
    ```

    Key decisions:
    - `branches: ["**"]`: runs on every branch push (not just main/develop) so issues are
      caught on feature branches before merge
    - `paths: ["**.sh"]`: only triggers on shell script changes — avoids CI noise on config
      file, markdown, or documentation commits (which make up most dotfiles repo commits)
    - `ludeeus/action-shellcheck@2.0.0`: pinned exact version for reproducibility
    - `severity: warning`: matches the pre-commit hook severity level (consistent local/CI behavior)
    - `ignore_paths: macos/zsh`: matches the pre-commit hook exclude — zsh files are skipped
      in both local and CI checks (consistent Pitfall 3 mitigation)
    - `actions/checkout@v4`: current stable checkout action
  </action>
