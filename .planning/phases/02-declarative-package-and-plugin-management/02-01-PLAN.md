1. Edit `.gitignore`: Remove line 26 (`nvim/lazy-lock.json`). This line currently blocks tracking of the Neovim lockfile. The file is only tracked because it was force-added previously -- removing the gitignore entry makes tracking explicit and robust (per Pitfall 2 from research, per D-11).

