### Gaps Summary

**Gap 1: Brewfile.lock.json (PKG-04)** -- This is a documented upstream change. Modern Homebrew 4.x no longer generates `Brewfile.lock.json` when running `brew bundle install`. The SUMMARY correctly documented this deviation and noted the Brewfile itself is the reproducibility guarantee (which the plan's own research confirmed). The ROADMAP success criterion #3 and REQUIREMENTS.md PKG-04 need updating to reflect this reality. This gap is non-blocking for the phase goal since the Brewfile itself ensures reproducibility.

**Gap 2: Stale gcloud symlink paths (minor)** -- The Brewfile was correctly updated to install `gcloud-cli` (renamed from `google-cloud-sdk`), but the `ensure_gcloud_symlink()` function in `initial-setup-macos.sh` still references the old `google-cloud-sdk` Caskroom paths. On a fresh machine, the symlink function may fail to find the Google Cloud SDK. This is a side effect of the Brewfile fix that was not propagated to dependent code.
